# Siphiwe Masinga — Portfolio

A dark, interactive 3D portfolio for Siphiwe Masinga: final-year BICT student at the University
of Mpumalanga, web developer, cybersecurity enthusiast and founder of ZOEBLOOM Pty Ltd.

## Features

- Interactive Three.js hero scene (crystal core, orbit rings, star field) that follows the
  mouse and reacts to scrolling
- 3D rotating skills sphere and 3D tilt on cards
- Sections for about, experience, projects, skills, certifications, education and contact
- Responsive layout, keyboard-friendly navigation, and reduced-motion support

## Run locally

Open `index.html` in a browser. There is no build step. Three.js and the fonts load from CDNs,
so an internet connection is needed for the 3D scene and typography.

## Files

- `index.html` — page content
- `styles.css` — layout and visual design
- `scene.js` — Three.js 3D hero scene
- `script.js` — navigation, typing effect, tilt cards, skills sphere and scroll reveals
- `images/` — profile photo, project screenshot and favicon

## Publish with GitHub Pages

In the repository settings, open **Pages**, choose **Deploy from a branch**, select `main`
and `/ (root)`, and save.
